# ✨ AI learning
Documenting my learning, approach and testing for AI.  


## 🔤 Simple, plain English
Use easy to understand English for flow steps.  
Use structure only when precision is needed.   
  
Flow steps are then:
1. Easy to understand (maintainable) ✅
2. Easy to check (auditable) ✅
3. Easy to change (flexible) ✅
4. Hard to break (resilient) ✅
  
Create flows with:  
1. 📏 Clear steps  
Say what you want, say what you don't want, and show an example so the AI understands.  

2. 🧩 Tiny pieces  
Break work into tiny bits, so problems are easy to spot and fix.  

3. 📋 Plan, run, check  
Decide the goal, test in small steps, and review everything before accepting it.
